# 🎵 Sound Conductor

Conduct an orchestra using hand movements.

## Category
Gesture Recognition

## Age Range
5+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Music creation
- Gesture control
- Record compositions

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your hand movements to conduct an orchestra and create music.
   - Experiment with different gestures to control tempo, volume, and instruments.
   - Record your compositions and play them back.
3. Quit: Press `q`.
