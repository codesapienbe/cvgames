# 🧱 Tetris Twist

Rotate and drop blocks using hand gestures.

## Category
Classic Games

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Hand gestures
- Tetris game
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use hand gestures to rotate and drop Tetris blocks.
   - Complete lines to score points and progress to higher levels.
   - Try to achieve the highest score possible.
3. Quit: Press `q`.
