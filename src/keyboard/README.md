# ⌨️ Virtual Keyboard

Type on a virtual keyboard using hand gestures detected by camera.

## Category
Utility

## Age Range
All ages

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Virtual keyboard
- Gesture-based typing
- Visual feedback

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Pinch your index and middle fingers to "click" on-screen keys.
   - Type as shown on the virtual keyboard.
3. Quit: Press `q`.
