# 🐍 Gesture Snake

Control the snake with body or hand movements.

## Description
Play the classic Snake game using your index fingertip to control the snake's direction. Guide the snake to eat donuts (food) to grow longer and increase your score. The game features smooth finger tracking for precise control.

## Category
Classic Games

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Body movements
- Snake game
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Move your index fingertip to steer the snake's head.
   - Guide the snake to eat donuts (food) to grow and increase your score.
   - Press `r` to restart the game at any time.
3. Quit: Press `q`.
