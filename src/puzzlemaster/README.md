# 🧩 Puzzle Master

Solve jigsaw puzzles by moving pieces with hand gestures.

## Category
Hand Tracking

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Drag and drop
- Multiple levels
- Timer

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Extend one finger and swipe your hand left/right/up/down to slide the empty tile.
   - Arrange tiles to form the ordered grid.
3. Quit: Press `q`.
