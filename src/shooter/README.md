# 🛸 Eye Shooter

Shoot down aliens by blinking or winking.

## Description
Control a spaceship with your head movements and shoot aliens by blinking. The game uses eye tracking to detect blinks and trigger shots. Destroy as many aliens as you can to increase your score—new aliens spawn over time.

## Category
Eye Tracking

## Age Range
8+

## Difficulty
Hard

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Blink detection
- Target shooting
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Move your head (nose tip) left/right to aim the spaceship.
   - Blink (eye aspect ratio below threshold) to shoot bullets.
   - Destroy aliens to increase your score; new aliens spawn over time.
3. Quit: Press `q` to exit.
