# 🧮 Virtual Calculator

Solve math problems by showing number gestures to the webcam.

## Category
Utility

## Age Range
6+

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Math problems
- Number gestures
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Show number gestures to the webcam to solve math problems.
   - The game recognizes your gestures and checks your answers.
   - Try to solve as many problems as possible for a high score.
3. Quit: Press `q`.
