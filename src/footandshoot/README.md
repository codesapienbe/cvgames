# Foot and Shoot

## Game Description

Foot and Shoot is a penalty shootout game where you control a player and try to score goals against a goalkeeper.

## Core Features

### ⚽ Body Movement Controls
	•	Shooting: Kick motion with right or left leg
	•	Ball placement: Body positioning determines shot direction
	•	Power control: Kick speed determines shot power
	•	Goalkeeper AI: Realistic goalkeeper reactions and saves
### 🎮 Game Mechanics
	•	Penalty shootout format with multiple rounds
	•	Physics-based ball movement with realistic trajectory
	•	Goalkeeper AI with different difficulty levels
	•	Score tracking and statistics
	•	Full-screen immersive experience
