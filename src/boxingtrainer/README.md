# 🥊 Boxing Trainer

Hit virtual pads or dodge objects by punching and moving.

## Category
Pose Tracking

## Age Range
10+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Punch detection
- Dodge mechanics
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Punch at virtual pads or dodge objects as they appear on the screen.
   - The camera tracks your movements and scores your performance.
   - Try to achieve the highest score possible.
3. Quit: Press `q`.
