# 🎮 Memory Match

Flip cards by looking or nodding with head.

## Category
Classic Games

## Age Range
6+

## Difficulty
Easy

## Duration
10-20 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Head tracking
- Memory game
- Timer

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your gaze or head movements to flip cards and find matching pairs.
   - Complete the game as quickly as possible to beat the timer.
   - Improve your memory and challenge yourself.
3. Quit: Press `q`.
