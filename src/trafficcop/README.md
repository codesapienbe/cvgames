# 🚦 Traffic Cop

Direct vehicle flow by making gestures for traffic lights.

## Category
Gesture Recognition

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Gesture input
- Traffic simulation
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use hand gestures to control traffic lights and direct vehicle flow.
   - Prevent accidents and keep traffic moving smoothly.
   - Score points for efficient traffic management.
3. Quit: Press `q`.
