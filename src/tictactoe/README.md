# ❌⭕ Tic Tac Toe

Play Tic Tac Toe by selecting cells with your gaze.

## Description
Play the classic Tic Tac Toe game using hand gestures to place X's and O's on the board. Point your index finger at a cell and pinch with your middle finger to place your mark. Players alternate turns, and the current player is shown on-screen.

## Category
Classic Games

## Age Range
5+

## Duration

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Eye tracking
- Tic Tac Toe
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Point your index finger at a cell and pinch with your middle finger (distance < threshold) to place a mark.
   - Players alternate between X and O; the next player is shown on-screen.
   - Press `r` to restart the game at any time.
3. Quit: Press `q`.
