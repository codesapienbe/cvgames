# ❓ Gesture Quiz

Answer trivia questions by gesturing to select options.

## Description
Answer trivia questions by moving your hand to select answers. Uses gesture recognition for input and tracks your score.

## Category
Quiz

## Age Range
8+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Gesture input
- Trivia questions
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Move your index fingertip to position the cursor.
   - Hover over an answer box for 1 second to select.
   - Answer as many trivia questions as you can for a high score.
3. Quit: Press `q`.
