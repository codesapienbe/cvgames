# 🎵 AR Musical Instrument

Play notes on a virtual piano or guitar using hand positions.

## Category
Utility

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Hand position
- Music creation
- Record compositions

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your hand positions to play notes on a virtual piano or guitar.
   - Create your own music and experiment with different sounds.
   - Record your compositions and play them back.
3. Quit: Press `q`.
