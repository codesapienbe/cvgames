# 🕷️ Jump Rope Simulator

Simulate skipping rope using hand and foot tracking.

## Category
Body Movement

## Age Range
8+

## Difficulty
Medium

## Duration
10-25 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Jump detection
- Timer
- Calorie counter

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Simulate jumping rope by moving your hands and feet as if using a real rope.
   - The game detects your jumps and tracks your performance.
   - Try to jump as many times as possible within the time limit.
3. Quit: Press `q`.
