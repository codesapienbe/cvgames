# 👋 Simon Says

Mimic gesture sequences shown by the game.

## Category
Gesture Recognition

## Age Range
5+

## Difficulty
Medium

## Duration
10-20 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Sequence memory
- Multiplayer
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Watch the gesture sequence shown by the game.
   - Mimic the gestures in the correct order to score points.
   - Challenge friends in multiplayer mode.
3. Quit: Press `q`.
