# 🏃‍♂️ Body Movement Challenge

Complete physical challenges using full body tracking.

## Category
Body Movement

## Age Range
All ages

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Full body tracking
- Physical challenges
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Follow the on-screen instructions to complete various physical challenges using your body movements.
   - Try to achieve the highest score possible.
3. Quit: Press `q`.
