# 🏓 Pong

Play classic Pong using hand tracking to control paddles.

## Category
Classic Games

## Age Range
All ages

## Difficulty
Medium

## Duration
10-20 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Hand tracking
- Paddle control
- Adjustable speed

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Move your left and right hands up/down to control paddles.
   - Press `f` to increase speed, `s` to decrease speed, `r` to reset the game.
3. Quit: Press `q`.
