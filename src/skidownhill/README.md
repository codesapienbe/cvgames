# ⛷️ Ski Downhill

Control a skier by leaning, crouching, or jumping.

## Category
Pose Tracking

## Age Range
8+

## Difficulty
Hard

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Pose tracking
- Obstacle course
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Lean, crouch, or jump to control your skier on the virtual slope.
   - Avoid obstacles and try to reach the finish line as fast as possible.
   - Score points based on your performance and speed.
3. Quit: Press `q`.
