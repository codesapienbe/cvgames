# 🖼️ Overlay

Overlay transparent images or logos onto your live camera feed using hand tracking.

## Category
Utility

## Age Range
All ages

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Image overlay
- Hand tracking
- Customizable logo

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - The demo overlays a transparent logo (`logo.png`) onto your live camera feed.
3. Quit: Press `q`.
