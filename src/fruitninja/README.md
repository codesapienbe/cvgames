# 🎯 Fruit Ninja CV

Slice flying fruit with hand swipes detected by camera.

## Category
Hand Tracking

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Swipe detection
- Score system
- Multiplayer

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your hand to swipe at flying fruit on the screen.
   - The camera detects your hand swipes to slice the fruit.
   - Try to slice as many fruits as possible and achieve a high score.
3. Quit: Press `q`.
