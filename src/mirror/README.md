# 🪞 Mirror

Detect and display your facial emotion in real time using your webcam.

## Category
Face Detection

## Age Range
All ages

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Emotion detection
- Real-time emoji feedback

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - The application detects and displays your facial emotion:
     - `Neutral`, `Happy`, or `Surprised` with an emoji.
3. Quit: Press `q`.
