# 📸 Selfie Fun

Take selfies with timed countdowns using smiles or gestures.

## Description
Take selfies by smiling at the camera to trigger a countdown. The photo is saved automatically, and you can use fun effects.

## Category
Face Detection

## Age Range
3+

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Smile detection
- Countdown timer
- Photo effects

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Smile to trigger a 3-second countdown.
   - The selfie is saved as `selfie_YYYYMMDD_HHMMSS.png`.
3. Quit: Press `q`.
