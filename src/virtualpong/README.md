# 🏓 Virtual Pong

Control the paddle with hand movements to play Pong.

## Category
Hand Tracking

## Age Range
6+

## Difficulty
Medium

## Duration
10-20 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Hand tracking
- Difficulty levels
- High scores

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Move your hand to control the paddle on the screen.
   - Hit the ball back and forth to score points.
   - Try different difficulty levels and aim for a high score.
3. Quit: Press `q`.
