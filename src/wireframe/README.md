# 🕸️ Wireframe

Create wireframe sketches using hand gestures detected by camera.

## Category
Utility

## Age Range
All ages

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Wireframe drawing
- Gesture-based controls
- Save sketches

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use hand gestures to draw wireframe sketches on the screen.
   - Save your sketches for later use.
3. Quit: Press `q`.
