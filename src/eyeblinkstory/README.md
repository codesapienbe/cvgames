# 👀 Eye Blink Story

Progress through an interactive story using eye blinks and expressions.

## Category
Eye Tracking

## Age Range
8+

## Difficulty
Medium

## Duration
15-45 min

## Requirements
- OpenCV
- MediaPipe
- dlib
- Python 3.7+
- Webcam

## Features
- Eye tracking
- Interactive story
- Multiple endings

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use eye blinks and facial expressions to make choices and progress through the story.
   - Experience different story paths and discover multiple endings.
   - Enjoy an interactive narrative controlled by your gaze.
3. Quit: Press `q`.
