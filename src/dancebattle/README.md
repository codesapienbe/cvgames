# 🤸 Dance Battle

Follow dance moves and compete with friends using full body tracking.

## Category
Body Movement

## Age Range
5+

## Difficulty
Hard

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Pose tracking
- Multiple songs
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Follow the dance moves shown on the screen using your full body.
   - Compete with friends to see who can match the moves best.
   - Try different songs and aim for a high score.
3. Quit: Press `q`.
