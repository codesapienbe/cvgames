# 🐶 Pet Simulator

Interact with a virtual pet using hand and face gestures.

## Category
Kids & Family

## Age Range
4+

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Pet interaction
- Gesture input
- Emotion feedback

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use hand and face gestures to interact with your virtual pet.
   - Watch your pet respond to your actions and emotions.
   - Take care of your pet and keep it happy.
3. Quit: Press `q`.
