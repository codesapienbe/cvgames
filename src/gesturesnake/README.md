# 🐍 Gesture Snake

Control the snake with body or hand movements.

## Category
Classic Games

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Body movements
- Snake game
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your body or hand movements to control the snake on the screen.
   - Eat food to grow longer and score points.
   - Avoid running into yourself or the walls.
3. Quit: Press `q`.
