# 🧱 Stack Blocks

Stack and balance virtual blocks using hand position.

## Category
Hand Tracking

## Age Range
6+

## Difficulty
Medium

## Duration
10-20 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Block placement
- Physics simulation
- Multiplayer

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your hand position to pick up and stack virtual blocks on the screen.
   - Try to balance the blocks as high as possible without toppling them.
   - Compete with friends in multiplayer mode.
3. Quit: Press `q`.
