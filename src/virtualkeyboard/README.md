# ⌨️ Virtual Keyboard

Type on a virtual keyboard using finger movements in mid-air.

## Category
Finger Tracking

## Age Range
8+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Finger movements
- Virtual keyboard
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your finger movements in the air to type on the virtual keyboard displayed on the screen.
   - The camera tracks your finger to detect key presses.
   - Try to type words or sentences as prompted by the game.
3. Quit: Press `q`.
