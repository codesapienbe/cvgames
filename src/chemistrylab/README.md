# 🧪 Chemistry Lab

Mix virtual chemicals using gesture-based tools.

## Category
Educational

## Age Range
10+

## Difficulty
Hard

## Duration
20-45 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Gesture input
- Experiment simulation
- Educational content

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use hand gestures to select and mix virtual chemicals.
   - Simulate real chemistry experiments in a safe, virtual environment.
   - Learn about chemical reactions and experiment outcomes.
3. Quit: Press `q`.
