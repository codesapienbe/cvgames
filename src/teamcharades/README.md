# 👥 Team Charades

Use body or facial expressions as clues for teammates.

## Category
Multiplayer

## Age Range
8+

## Difficulty
Medium

## Duration
15-45 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Multiplayer
- Gesture input
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your body or facial expressions to act out clues for your teammates.
   - Guess the word or phrase based on the clues given.
   - Compete in teams and try to score the most points.
3. Quit: Press `q`.
