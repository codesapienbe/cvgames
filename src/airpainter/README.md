# 🎨 Air Painter

Draw and paint in the air using finger movements.

## Category
Finger Tracking

## Age Range
4+

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Finger tracking
- Color selection
- Save artwork

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Pinch your thumb and index finger (distance < threshold) to draw.
   - Hover over "brush", "eraser", or "clear" on the left for 3 seconds to select tools.
   - Hover over color swatches at the bottom for 3 seconds to change colors.
3. Quit: Press `q`.
