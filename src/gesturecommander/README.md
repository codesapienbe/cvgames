# 🎚️ Gesture Commander

Control a spaceship with hand gestures.

## Category
Gesture Recognition

## Age Range
8+

## Difficulty
Hard

## Duration
15-40 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Complex gestures
- Adventure mode
- Leaderboards

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use complex hand gestures to control your spaceship in adventure mode.
   - Compete for the highest score on the leaderboards.
   - Master different gestures to unlock new abilities.
3. Quit: Press `q`.
