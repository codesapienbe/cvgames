# 🧱 Tetris

Rotate and drop blocks using hand gestures.

## Description
Play the classic Tetris game using hand gestures to control the falling blocks. Pinch your fingers to activate controls, then move your hand to shift and rotate pieces. Clear lines to earn points and level up as you progress.

## Category
Classic Games

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Hand gestures
- Tetris game
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Pinch index and middle fingers (distance < threshold) to activate controls.
   - Move your hand left/right to shift the falling piece.
   - Raise your hand above half the board to rotate the piece.
   - Clear lines to earn points; level up as you clear more lines.
   - Press `r` to restart when the game is over.
3. Quit: Press `q`.
