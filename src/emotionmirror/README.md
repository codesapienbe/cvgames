# 😊 Emotion Mirror

Mirror different emotions and expressions in a face-tracking game.

## Category
Face Detection

## Age Range
3+

## Difficulty
Easy

## Duration
5-15 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Face detection
- Emotion recognition
- Educational content

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Watch the emotion or expression shown on the screen.
   - Try to mirror the emotion using your face.
   - Learn about different emotions in a fun, interactive way.
3. Quit: Press `q`.
