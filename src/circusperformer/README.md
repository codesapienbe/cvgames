# 🎪 Circus Performer

Balance virtual objects and perform circus tricks using body movements.

## Category
Body Movement

## Age Range
6+

## Difficulty
Medium

## Duration
10-25 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Body tracking
- Physics simulation
- Achievement system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your body movements to balance objects and perform circus tricks.
   - Unlock achievements as you master new skills.
   - Try to keep objects balanced for as long as possible.
3. Quit: Press `q`.
