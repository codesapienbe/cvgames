# 🏡 VR Hide & Seek

Hide and seek using body silhouette for hiding/peeking.

## Category
Multiplayer

## Age Range
6+

## Difficulty
Hard

## Duration
15-45 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Body silhouette
- Multiplayer
- Virtual environment

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your body silhouette to hide or peek in the virtual environment.
   - Play with friends in multiplayer mode.
   - Try to avoid being found or find others as quickly as possible.
3. Quit: Press `q`.
