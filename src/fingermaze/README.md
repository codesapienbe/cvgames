# 🧵 Finger Maze

Navigate a virtual ball through a maze using finger movements.

## Category
Finger Tracking

## Age Range
6+

## Difficulty
Medium

## Duration
10-25 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Maze navigation
- Timer
- Multiple levels

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your finger movements to guide the virtual ball through the maze.
   - Complete each level as quickly as possible to beat the timer.
   - Progress through multiple maze levels of increasing difficulty.
3. Quit: Press `q`.
