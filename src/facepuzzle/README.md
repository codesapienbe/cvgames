# 🖼️ Face Puzzle

Rearrange shuffled images of your own face using facial landmarks.

## Category
Face Detection

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Landmark tracking
- Puzzle solver
- Timer

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use facial landmarks to rearrange shuffled pieces of your face image.
   - Solve the puzzle as quickly as possible to beat the timer.
   - Try different puzzle difficulties and challenge yourself.
3. Quit: Press `q`.
