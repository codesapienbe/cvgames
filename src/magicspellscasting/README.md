# ⚡ Magic Spells Casting

Cast spells by drawing patterns in the air with your fingers.

## Category
Finger Tracking

## Age Range
8+

## Difficulty
Hard

## Duration
15-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Pattern recognition
- Spell effects
- Story mode

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Draw specific patterns in the air with your fingers to cast spells.
   - Unlock new spells and progress through the story mode.
   - Experiment with different gestures to discover hidden effects.
3. Quit: Press `q`.
