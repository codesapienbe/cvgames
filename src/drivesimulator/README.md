# 🕹️ Drive Simulator

Drive a virtual car using steering wheel hand gestures.

## Category
Adventure

## Age Range
8+

## Difficulty
Medium

## Duration
15-45 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Steering control
- Multiple tracks
- Speed challenges

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use steering wheel hand gestures to control your virtual car.
   - Race on multiple tracks and try to beat speed challenges.
   - Improve your driving skills and aim for the best time.
3. Quit: Press `q`.
