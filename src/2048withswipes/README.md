# 🕹️ 2048 with Swipes

Play 2048 by swiping in the air with your hands.

## Category
Hand Tracking

## Age Range
8+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Swipe detection
- Score system
- Undo option

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Swipe your hand in the air (left, right, up, or down) to move the tiles.
   - Combine tiles with the same number to reach 2048.
   - Use the undo option if you make a mistake.
3. Quit: Press `q`.
