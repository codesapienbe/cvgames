# 🗣️ Gesture Drawing

Collaborate to draw on a shared canvas using gestures.

## Category
Gesture Recognition

## Age Range
8+

## Difficulty
Medium

## Duration
15-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Multiplayer
- Gesture input
- Save artwork

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use hand gestures to draw on the shared canvas.
   - Collaborate with others in multiplayer mode.
   - Save your artwork when finished.
3. Quit: Press `q`.
