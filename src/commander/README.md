# 🚀 Commander

Control a spaceship using hand gestures.

## Category
Gesture Recognition

## Age Range
All ages

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Spaceship control
- Gesture-based navigation
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Point with your index finger to set the spaceship direction.
   - Open palm (3+ fingers) to thrust and accelerate.
3. Quit: Press `q`.
