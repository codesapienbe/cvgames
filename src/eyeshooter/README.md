# 🛸 Eye Shooter

Shoot down aliens by blinking or winking.

## Category
Eye Tracking

## Age Range
8+

## Difficulty
Hard

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Blink detection
- Target shooting
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Blink or wink to shoot at alien targets on the screen.
   - Try to shoot down as many aliens as possible for a high score.
   - The game gets harder as you progress.
3. Quit: Press `q`.
