# 💥 Whack-a-Mole AR

Whack virtual moles popping up by tapping with your hands.

## Category
Hand Tracking

## Age Range
5+

## Difficulty
Easy

## Duration
5-15 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Tap detection
- Score tracking
- Speed levels

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your hand to tap on virtual moles as they appear on the screen.
   - Try to whack as many moles as possible before time runs out.
   - The game increases in speed as you progress.
3. Quit: Press `q`.
