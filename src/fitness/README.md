# 🏋️ Fitness Pose Module

Monitor and improve your exercise form using pose estimation.

## Category
Fitness

## Age Range
All ages

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Pose estimation
- Real-time feedback
- Exercise monitoring

## How to Play
1. Run:
   ```bash
   python PoseModule.py
   ```
2. Play:
   - A window shows your pose landmarks and real-time FPS.
   - Use it to monitor and improve your exercise form.
3. Quit: Press `q`.
