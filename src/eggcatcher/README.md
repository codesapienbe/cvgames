# 🥚 Egg Catcher

Catch falling eggs by moving your hand under them.

## Category
Hand Tracking

## Age Range
5+

## Difficulty
Easy

## Duration
5-15 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Hand tracking
- Score system
- Speed increase

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Move your hand under the falling eggs to catch them before they hit the ground.
   - The game gets faster as you progress.
   - Try to catch as many eggs as possible for a high score.
3. Quit: Press `q`.
