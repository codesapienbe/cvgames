# 🗣️ Language Tutor

Practice sign language recognition or translation.

## Category
Educational

## Age Range
8+

## Difficulty
Medium

## Duration
15-45 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Gesture recognition
- Language learning
- Progress tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use hand gestures to practice sign language or translation tasks.
   - The game recognizes your gestures and provides feedback.
   - Track your progress as you learn new signs and words.
3. Quit: Press `q`.
