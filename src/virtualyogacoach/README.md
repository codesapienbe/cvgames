# 🧘 Virtual Yoga Coach

Follow yoga poses and receive correctional cues.

## Category
Pose Tracking

## Age Range
10+

## Difficulty
Medium

## Duration
15-45 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Pose detection
- Pose correction
- Workout plans

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Follow the yoga poses shown on the screen.
   - Receive real-time correctional cues to improve your form.
   - Complete different workout plans and track your progress.
3. Quit: Press `q`.
