# 🏃 Runner Adventure

Endless runner controlled by lateral body movements.

## Category
Body Movement

## Age Range
8+

## Difficulty
Medium

## Duration
10-20 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Lateral movement
- Obstacle avoidance
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Move your body left or right to control your character in the endless runner game.
   - Avoid obstacles and collect points as you run.
   - Try to achieve the highest score possible.
3. Quit: Press `q`.
