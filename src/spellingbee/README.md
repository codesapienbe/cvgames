# 🔤 Spelling Bee

Spell words by forming letters with hand gestures.

## Category
Educational

## Age Range
6+

## Difficulty
Medium

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Letter gestures
- Word challenges
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Form letters with your hand gestures to spell words shown on the screen.
   - Complete word challenges and try to achieve the highest score.
   - Practice spelling in a fun, interactive way.
3. Quit: Press `q`.
