# 🥅 Soccer Trainer

Practice football/soccer skills with real-time feedback.

## Category
AR Sports

## Age Range
10+

## Difficulty
Medium

## Duration
15-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Kick detection
- Dribble tracking
- Skill challenges

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Practice your football/soccer skills in front of your webcam.
   - The game detects your kicks and dribbles, providing real-time feedback.
   - Complete skill challenges and improve your performance.
3. Quit: Press `q`.
