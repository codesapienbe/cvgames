# 🎯 Archery Simulator

Aim and shoot virtual arrows using arm and hand tracking.

## Category
AR Sports

## Age Range
8+

## Difficulty
Medium

## Duration
10-25 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Aiming system
- Target practice
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your arm and hand movements to aim and shoot virtual arrows at targets.
   - Practice your aim and try to achieve the highest score possible.
   - Progress through different target challenges.
3. Quit: Press `q`.
