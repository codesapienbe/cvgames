# 👀 Eye Blink Story

Progress through an interactive story using eye blinks and expressions.

## Description
An interactive storytelling experience where you control the narrative progression by blinking your eyes. The game tracks your eye movements and blinks to advance through the story, creating an immersive reading experience with multiple possible endings.

## Category
Eye Tracking

## Age Range
8+

## Difficulty
Medium

## Duration
15-45 min

## Requirements
- OpenCV
- MediaPipe
- dlib
- Python 3.7+
- Webcam

## Features
- Eye tracking
- Interactive story
- Multiple endings

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Blink to advance the story to the next line.
   - Follow on-screen text as the story progresses.
3. Quit: Press `q`.
