# 🏂 Balance Board

Simulate balancing on a virtual surfboard or slackline.

## Category
Pose Tracking

## Age Range
8+

## Difficulty
Medium

## Duration
10-20 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Balance tracking
- Timer
- Score system

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your body to simulate balancing on a virtual board or line.
   - Try to maintain your balance for as long as possible.
   - Watch the timer and aim for a high score.
3. Quit: Press `q`.
