# ❌⭕ Eye Tic Tac Toe

Play Tic Tac Toe by selecting cells with your gaze.

## Category
Classic Games

## Age Range
5+

## Difficulty
Easy

## Duration
10-30 min

## Requirements
- OpenCV
- MediaPipe
- Python 3.7+
- Webcam

## Features
- Eye tracking
- Tic Tac Toe
- Score tracking

## How to Play
1. Run:
   ```bash
   python __init__.py
   ```
2. Play:
   - Use your gaze to select cells and play Tic Tac Toe.
   - Try to win against the computer or another player.
   - Track your wins and improve your strategy.
3. Quit: Press `q`.
